Tutaj znajduje się tablica HARDCODED_QUESTIONS w formacie JSON. Możesz ją dowolnie modyfikować lub wkleić gotowy zestaw pytań:

Jak wrzucić ten quiz na własną domenę GitHub Pages?

  1. Dostosuj pytania w zakładce Lista Pytań do swojej prezentacji.
  2. Kliknij zielony przycisk na dole: "Pobierz gotowy index.html (z pytaniami na sztywno)".
  3. Wgraj pobrany plik index.html do swojego repozytorium na GitHubie i włącz Settings → Pages.
  4. Aby synchronizacja między różnymi telefonami działała również na zewnętrznej domenie GitHub Pages, możesz poniżej wkleić darmowy obiekt firebaseConfig z konsoli Firebase (Realtime/Firestore) – zostanie on automatycznie zaszyty w pobranym pliku!

*W obecnym podglądzie chmura multiplayer działa automatycznie od razu bez wpisywania kluczy.
